  概要
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  本ソフトウェアは、任意のバージョンのWinMUGENに対して、
 AssertSpecialのNoBarDisplayを無効化するように変更するパッチです。

  技術詳細
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 0x47DD9Bを
  0x08（NoBarDisplayの種別ID）　　　　　から
  0x0B（いずれの命令とも一致しないID）　に変更しています。
 この変更による隔離キャラへの影響はないと考えられます。

  また、UPX圧縮がなされているWinMUGENに対しては、解凍->書き換え->
 圧縮を行っております。UPXの圧縮アルゴリズムの性質上、上記に示す
 ような1Byteの書き換えであっても圧縮後のファイルには多数の違いが
 生じてしまいます。当然、解凍後ファイルには1Byteの違いしか残りま
 せんが、解凍前の内容もメモリ上には依然として存在するため、正常に
 動作しないキャラが出てくる可能性も考えられます。ご了承ください。
